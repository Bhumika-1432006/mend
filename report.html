## Chosen fix: Add a targeted edit_file (exact string replace) tool and steer edits away from whole-file rewrites

File: `mend/worker.py`

1) Add a new tool to TOOLS named "edit_file". Description: "Edit a file by replacing one exact occurrence of `old` with `new`. `old` must match the file's current text exactly (including indentation; do not include the line-number prefixes shown by read_file) and must occur exactly once - include enough surrounding lines to make it unique. Prefer this over write_file for any change to an existing file." The input_schema is an object with required string properties `path`, `old` and `new`, plus additionalProperties false.
2) Implement it as `@neatlogs.span(kind="TOOL", tool_name="edit_file") def edit_file(work, path, old, new)`. It should:
- resolve the path with _safe_path;
- refuse paths under tests, the same way write_file does;
- read the text;
- count = text.count(old); if count == 0 raise ValueError("`old` not found in file; re-read the exact lines and copy them verbatim"); if count > 1 raise ValueError(f"`old` occurs {count} times; include more surrounding context");
- write text.replace(old, new, 1);
- return f"edited {path}: replaced {old.count(chr(10))+1} line(s) with {new.count(chr(10))+1} line(s)".
Register it in HANDLERS.
3) Change write_file's tool description to: "Create a new file or replace the WHOLE content of a file. Anything you omit is deleted. To change part of an existing file use edit_file instead."
4) In read_file, when the returned chunk ends before the end of the file, append a final line: f"... ({len(text) - (start - 1 + len(chunk))} more lines; file has {len(text)} lines total)". This makes partial reads visible.

Why it is general: The dominant cost across these traces is that the only way to change code is to regenerate a whole file. That silently truncates any file longer than what the model has read (task 23 failed, task 24 nearly failed) and makes even successful one-line fixes slow (task 22). A precise string-replace edit tool, plus a visible marker on partial reads, removes this failure mode for any bug in any file of any length. It contains nothing specific to this library or these tasks.
