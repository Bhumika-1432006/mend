How it works

A self-repair loop with a hard gate.

01Run

A worker agent fixes planted bugs in a real codebase: 29 tasks, judged by the test suite, not by the agent.

02Trace

Every model call and tool call is a span in neatlogs, with inputs, outputs, tokens and cost.

03Diagnose

A supervisor pulls failed and wasteful runs back over the neatlogs MCP server and finds the step that went wrong.

04Patch

Claude Code applies one general fix to the worker: never a task-specific hack, never the tests.

05Checkpoint

Entire links the commit to the session that wrote it, so every self-fix carries its reasoning.

06Prove

The whole suite re-runs. More tasks solved, or the same with 15% fewer tokens: kept. Anything else: reverted.

The first bug Mend found in itself

It was deleting the end of long files.

Reading its own neatlogs traces, the supervisor saw the worker read only the first 200 lines of a 233-line file, then rewrite the whole file to change one word. Everything after line 200 was silently gone. The fix it wrote for itself: Add a targeted edit_file (exact string replace) tool and steer edits away from whole-file rewrites.
